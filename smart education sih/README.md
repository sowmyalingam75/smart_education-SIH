# Smart Education SIH

## Project Overview
Smart Education SIH is a smart learning platform designed to improve the educational experience through interactive learning tools and student performance tracking.

## Features
- Student Dashboard
- AI Assistant
- AI Tutor
- Attendance Management
- Student Performance Tracking
- Quiz Management
- Study Planner
- Learning Materials
- At-Risk Student Identification
- Progress Reports

## Technologies Used
- React.js
- Vite
- JavaScript
- CSS

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/sowmyalingam75/smart_education-SIH.git
   ```

2. Open the project folder.

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npm run dev
   ```
